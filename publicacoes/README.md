## Como ler os diretórios

Cada entrada externa informa finalidade, situação observada e última checagem. A data **2026-11-17** significa que houve uma tentativa de consulta nessa data, não que todos os serviços funcionaram integralmente, que o conteúdo foi atualizado nesse dia ou que continuam disponíveis agora.

- **Conteúdo conferido:** o Exa recuperou texto pertinente em consulta forçada ao vivo.
- **Interface conferida; operação não verificada:** a página apareceu, mas resultados, login ou funcionalidades não foram exercitados.
- **Destino inadequado:** a URL devolveu conteúdo diferente do esperado.
- **Não confirmado:** houve timeout ou extração vazia; isso não prova encerramento ou erro HTTP do site de origem.
- **Aposentado informado:** a própria página declara descontinuação ou unificação.

Nenhuma entrada é um selo de segurança, de conformidade legal ou de qualidade profissional. Não copiamos classificações de praias, calendários ou avisos dinâmicos para tratá-los como informação permanente.
