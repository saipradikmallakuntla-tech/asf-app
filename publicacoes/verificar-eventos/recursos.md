## Confirmação por canal independente

Use as referências institucionais para localizar o responsável; compare os detalhes com a fonte que você já conhece. Não copie contatos de mensagens suspeitas para tratá-los como oficiais. Não deduza uma agenda atual a partir de uma notícia histórica ou de um satélite aposentado.

Nenhum evento foi incluído como ativo nesta edição porque não houve confirmação específica de uma programação. Essa ausência é intencional: um diretório pode orientar a verificação sem inventar uma lista.
